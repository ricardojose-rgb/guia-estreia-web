# Guia de Estreias (web)

Versão para computador (PC e Mac) do Guia de Estreias: séries, anime e filmes com as datas de estreia dos EUA e a hora em Portugal.

**Abrir:** https://ricardojose-rgb.github.io/guia-estreia-web/

- **Para ver**: o próximo episódio de cada série, com botão Visto.
- **Agenda**: séries (datas dos EUA), anime (hora de Portugal) e filmes.
- **Séries**: as tuas séries com progresso.
- **Descobrir**: pesquisa, mais aguardadas, estreias de séries, anime e filmes.
- Clicar num poster abre a imagem em grande.

As tuas séries, os episódios vistos e as chaves ficam guardados só no teu browser.
Para trazer os dados da app Android: na app, Definições → Exportar; aqui, Definições → Importar.

**Instalar como app:** no Chrome ou no Edge, carrega no ícone de instalar na barra de endereço. No Safari (Mac), Ficheiro → Adicionar à Dock.

Dados: TVmaze (CC BY-SA), AniList, TMDB (este produto usa a API do TMDB mas não é endossado nem certificado pelo TMDB) e OMDb.

## Desenvolvimento
`npm install`, `npm run dev`. Cada push para `main` publica o site no GitHub Pages.
